# QQ 人格机器人（qq-persona-bot）

一个跑在自己电脑上的**私人 QQ 聊天机器人**：桌面窗口 + 托盘常驻。整个面板围绕**主对话**组织——她记得的、主动聊的、接着话头说的，都在主对话里；群聊和别的私聊只当背景板。
协议端用 [SnowCat](https://github.com/DandanLLab/SnowCatQQ)（NapCat 内核 + V8 注入，OneBot v11，附 QQ 9.9.37 便携运行时）；
模型接任意 OpenAI 兼容接口（DeepSeek / 中转站 / 本地 vLLM 都行）。

## 它是什么

- **桌面程序**：双击 `start.cmd` 就打开一个独立窗口，不再需要浏览器；关窗口是收进托盘，托盘菜单里能重新打开。
- **人格可换**：一个号可以有多套人格（说话方式、性格、开场白、温度），私聊/群聊/单个联系人可以各自指定，也支持跟着全局默认走。
- **懂 QQ**：内置 QQ 常识与网络用语——私聊/群聊的区别、@ 与引用、戳一戳、撤回、表情包、群公告，以及当前流行的梗和网络词，按场景自动注入提示词，不用自己写。
- **主对话优先**：打开面板就是主对话，单栏铺满、气泡更大；人格、记忆、导出都在页头。其他会话折叠进「其他会话」，只用来翻阅和临时调整。
- **对话记录**：所有私聊与群聊消息存在本地 SQLite，面板里能翻历史、搜昵称、导出成 txt、清空、置顶、写「会话记忆」。
- **触发规则**：私聊/群聊分别开关，群里可要求 @ 或叫唤词，支持黑白名单、随机搭话概率、回复冷却。
- **像人在打字**：连发消息合并、按句拆成多条气泡、随机间隔、清理 Markdown，尽量不像机器人。
- **会主动找你**：指定一个「主对话」，它记住的上下文几乎不设上限；闲下来会隔一阵自己找话题（「在干嘛呢」），你一直不回还会追问一句（「怎么不理我」），但有限次、避开深夜。
- **会发表情包**：把 QQ 收藏夹里的表情同步到本地，想发时直接发图；也能识图——配好一个多模态模型，别人发的图它先「看一眼」再回。

## 运行要求

- Windows 10 / 11，64 位
- Node.js **22.5 以上**（用到内置 `node:sqlite`；22 LTS 即可）
- 能访问 npm 源（首次安装依赖）和模型 API
- 不需要另外装 QQ，但要自己放一份协议端：GitHub 上的仓库**只包含代码**，`protocol/`（1.4 GB，含 QQ 运行时和登录凭据）、`llbot/`、`data/`、`node_modules/` 都不入库。见下面「从 GitHub 部署」。

## 快速开始

1. 双击桌面上的 **QQ人格机** 快捷方式（直接启动窗口，不经过 `.cmd`）；想看到控制台和启动日志，就双击同目录的 `start.cmd`。
2. 首次启动会自动做三件事：装依赖、装桌面壳（Electron，约 260 MB）、打开窗口。耐心等几分钟。
3. 窗口里进「设置」，填模型 API Key（默认 DeepSeek），点「测试连接」。
4. 双击 `start-snowcat.cmd` 启动内置 QQ，再按下一节登录/上线。

> 窗口没出来也没关系：脚本会等窗口真正加载完面板，最多等 40 秒，还不行就自动回退成浏览器面板，并在控制台告诉你怎么排查。
> 退出方式：托盘图标右键 →「退出」；直接关窗口只是收进托盘。

## 从 GitHub 部署

克隆下来只有代码，跑起来还要补两样东西：

1. **依赖**：在项目根目录 `npm install`（会装 `ws` 和桌面壳 Electron，约 260 MB）。或者直接双击 `start.cmd`，它发现缺依赖会自己装。
2. **协议端**（二选一）：
   - **省事**：从已经跑起来的那台机器上，把整个 `protocol/snowcat/` 目录拷过来（自包含：QQ 9.9.37 运行时 + `winmm` 注入 + `napcat.mjs` + 预配的 `onebot11_<QQ号>.json`），放到项目根的 `protocol/snowcat/` 下即可；
   - **从头装**：下载 [SnowCatQQ](https://github.com/DandanLLab/SnowCatQQ) 的源码包，按它 `release-tools/` 里的 `snowcat-run.ps1` 组装一个便携 QQ 目录（需要一份 QQ 9.9.37 运行时），再把 `winmm-v8.dll`、`snowcat-boot.js`、`napcat.mjs`、`webui-static/` 按脚本说明放进去。

放好之后：`npm start`（或双击 `start.cmd`）→ 面板打开 → 双击 `start-snowcat.cmd` → 按下一节扫码登录。

> `start-llbot.cmd` 是早期 LLBot 方案的启动器，那个渠道已关闭新用户注册，仓库里不再附带，可以忽略。

## 接入 QQ（SnowCat）

> 不需要装 NapCat，也不需要装 QQ。协议端和 QQ 运行时都在 `protocol\snowcat\SnowCat.9.9.37.Shell` 里，已预配好反向 WS。

1. 双击项目根目录的 `start-snowcat.cmd`：先确认面板在跑，再启动内置 QQ。
2. 打开雪猫后台 <http://127.0.0.1:6099/webui/>，用手机 QQ 扫码登录一个**小号**；登录过一次后，下次启动会自动恢复。
3. 登录成功后，内置的 OneBot 11 会自动连到面板的 `ws://127.0.0.1:7801/onebot`，左上角变「在线」，用另一个号发消息试试。

预配的连接参数在 `protocol\snowcat\SnowCat.9.9.37.Shell\config\onebot11_<QQ号>.json` 的 `network.websocketClients` 里：

```json
{ "name": "QQ人格机", "enable": true, "url": "ws://127.0.0.1:7801/onebot", "messagePostFormat": "array", "token": "", "heartInterval": 30000, "reconnectInterval": 3000 }
```

> 改过面板端口或设了 Token 时，把 `url` 一起改掉（面板「设置 → 接入步骤 → 复制接入地址」会生成带 token 的地址），或在雪猫后台的网络配置里改。
> 雪猫后台只用来管 QQ 登录和协议端配置；人格、对话记录仍然在本项目面板里管，两边互不冲突。

## 面板里有什么

| 页面 | 用途 |
| --- | --- |
| 概览 | 在线状态、今日/累计消息量、最近会话、运行日志、接入地址一键复制 |
| 人格 | 新建/编辑/删除人格，设默认；温度留空表示跟随全局；每个人格可加「补充知识/口癖」 |
| 主对话 | 打开面板的默认页：单栏全宽展示当前主对话，可切换人格、写记忆、导出、清空、以机器人身份代发；还没设主对话时会让你从现有会话里挑一个 |
| 其他会话 | 左侧搜会话（昵称/QQ/群号），右侧看完整对话；右上角下拉框可单独给这个会话指定人格（默认跟随全局）；可导出、清空、置顶、写会话记忆、以机器人身份代发；右上角 ☆ 可设为主对话（记忆不设上限 + 主动找话题） |
| 触发规则 | 私聊/群聊开关、@ 要求、叫唤词、黑白名单、随机搭话、冷却、拆气泡间隔、Markdown 清理、QQ 常识注入开关、主对话 / 主动间隔 / 没回就追问、表情包库 |
| 连接 | 纯展示页：机器人（账号、连接方式、最近一条消息、模型/识图是否就绪、主对话、运行时长）、DSH 通道（开关、触发词、命令、工作目录、超时、主动消息节奏）、任务流水（最近 20 次转交的时间/来源/内容/状态/耗时/退出码，3 秒自动刷新） |
| 设置 | 模型 API、识图模型（可选）、OneBot 端口与 Token、SnowCat 接入步骤、数据统计 |

## 它是怎么回话的

```
QQ 消息 → SnowCat（napcat 内核）→ 反向 WebSocket(:7801) → 过滤（黑白名单/触发规则/自己发的）
        → 合并连发消息（800ms 去抖）→ 取人格 + 最近 N 条历史 + QQ 知识 → 调模型
        → 清理 Markdown → 按句拆成 1~3 条 → 随机间隔发出 → 逐条落库
```

几点刻意的设计：

- **主对话**：在「其他会话」里把某个会话设为主对话（右上角 ☆ 主对话），或者第一次打开「主对话」时直接挑一个。

主动开口不是定时群发，而是先分清两种局面（`server/proactive.js` 的 `describe()`）：

- 上一句像在**等你回**（有问号、或以「吗/呢/嘛」收尾）→ 到点轻轻催一句（「人呢」「怎么不理我」），第一次客客气气，第二次才带点小情绪；同一轮最多催 `followup_max` 次；
- 上一轮**已经聊完**（你道了晚安、只回了个「嗯/好」，或者追问次数用完了）→ 起一个**全新话题**，明着不接旧话；
- 时间还不到、或者你刚说完话，就什么都不发。
它是你们的主要聊天：
  - 上下文不按「携带最近多少条」截断，而是按字符预算（默认 24000 字符）尽量装满，几十上百轮都记得；
  - 空闲时（默认 45 分钟没人说话）它会自己找话题发消息（「在干嘛呢」这类随口开场），间隔在 90–240 分钟之间随机，避开 00:30–08:30，每天最多 5 条；
  - 这些都能在「触发规则 → 主对话与主动消息」里改，还有一个「现在试一条」按钮用来验证效果；
  - 主动消息在对话记录里标成 `sender=主动`，方便区分。
  - **没回就追问**：它发完消息你一直没接，默认过 20 分钟会半开玩笑追问一句（「怎么不理我」「人呢」），同一条消息最多追问 2 次就停，不会连环轰炸；追问也算在每天 5 条上限里。
- **人格优先级**：会话指定 > 联系人指定 > 全局默认。主对话页头（或「其他会话」）右上角的下拉框直接改当前会话的人格；改默认人格，所有「跟随默认」的会话一起变。
- **上下文窗口**：默认带最近 12 条消息，群聊里给用户消息加「昵称：」前缀，模型能分清谁在说话。
- **冷却与并发**：同一会话两次回复至少隔 1.2 秒，全局最多 3 个请求同时在跑，避免刷屏和被限流。
- **开场白**：第一次跟某人说话时先发人格自带的 greeting，再回正文。
- **QQ 常识层**：`server/qq-knowledge.js` 里维护「基础玩法 / 私聊 / 群聊 / 表情包 / 别露馅 / 网络用语」，按场景裁剪后注入；私聊不带群聊规则，群聊才追加 @ 与刷屏克制。
- **识图**：默认关。在「设置 → 识图（可选）」填一个支持图片输入的模型（如 `qwen-vl-max`、`glm-4v`、`gpt-4o-mini`，Base URL 与 Key 留空则跟随主模型），打开开关后，别人发来的图片会先被识别成一句中文描述再交给聊天模型——它「看」到的就是描述，而不是原图。识别失败不影响聊天，只是退化成 `[图片]` 占位。
  - 点「测试识图」会**先保存当前表单再测**，所以填完直接点就行；如果模型其实不认图片，这里会直接显示服务商返回的错误。
  - 实测 DeepSeek 的 `deepseek-chat` 走 `image_url` 也能返回描述（虽然不是官方宣传的多模态模型），想更稳可以换明确的视觉模型。
- **表情包**：`触发规则 → 表情包库 → 从 QQ 收藏同步`，会把账号收藏夹里的表情下到 `data/stickers/`，提示词里告诉它「你有 N 个表情包，想发时在最后单独写一行 `[[sticker]]`」；发出去的是图片段，记录里显示 `[表情包]`。
  - 点缩略图可以停用/启用，停用的不会被抽到；「额外随缘配图概率」控制它没主动想发时顺手配一张的频率，0 表示只按意愿发。
  - 每次发送会优先挑用得少的，避免同一张反复出现。

## 数据与备份

- 全部记录：`data/bot.db`（SQLite，WAL 模式）。备份仓库整个 `data/` 目录即可。
- 桌面壳日志：`data/desktop.log`（窗口没出来时先看这里）。
- 表情包原图：`data/stickers/`（按内容 sha1 命名，重复同步会自动去重）。
- 模型 Key 只存在本地 `bot.db`，面板和日志里都不回显。

## 一次回复发几条

她不会一句一句往外蹦，也不会糊成一大段：

- 一段完整回复默认拆成 **1–2 条气泡**（`reply_max_parts = 2`，可在「触发规则 → 说话方式」里改 1–5）；
- 顺序是**先接住你的上文**（回应你说的词、情绪、疑问），后面的气泡才是她自己的想法、追问或补充；
- 每条不超过 30 字，换行分隔；真的没什么可说时才只发一条（「嗯」「哈哈」「睡吧」）；
- 情绪上头时（起伏 ≥58 / ≥78）实际条数会放宽到 2 / 4 条，间隔也缩短，看起来像人在快速连打。

## 情绪条（面板里看得到、QQ 里看不到）

每个人的对话都有一份隐藏的心情状态（`server/mood.js` + `moods` 表），三个量，0–100：

- **心情**：被夸、被哄会往上走；被敷衍（只回「嗯」「哦」）、被凶会往下掉；
- **起伏**：情绪强度，越高越容易「噼里啪啦连发几条」，越低就越平静、一次只说一句；
- **精力**：话多话少、句子长短。

它会在主对话页头显示成两条小进度条（心情 / 起伏），QQ 那一侧完全看不到——模型只知道「你现在心情如何」，不会把数字说出口。

**它怎么影响说话**：

- 系统提示里多一段【你现在的心情】（心情好→愿意多说、心情低落→句子变短、情绪上头→标点更用力）；
- 情绪强度 ≥58 时，同一条回复允许拆成 2 条气泡；≥78 时最多 4 条，且两条之间的间隔缩短到 0.2–0.6 秒，看起来更像人在快速连打；
- 说完之后起伏会回落一点，时间久了向基线慢慢漂回，不会一直记仇也不会一直亢奋。

想手动调着玩，`PATCH /api/mood/<会话id>`（`{"valence":70,"arousal":85}`），面板的情绪条会跟着动。

## 连接页（看看两边通没通）

面板左侧「连接」一页把三件事摊开，只读、不提供操作：

- **机器人**：是否已连上（`reverse` 还是 `forward`）、端口、最近一条消息是多久之前、模型和识图各自是否就绪、当前主对话、这个进程跑了多久；
- **DSH 通道**：转交开关、触发关键词、实际执行的命令（自动检测到的 CLI 路径）、工作目录、单次超时、主动消息与「没回就追问」的节奏；
- **任务流水**：最近 20 次转交的时间、来源会话、内容摘要、状态（运行中 / 完成 / 失败）、耗时、退出码。

页面在打开时每 3 秒刷新一次，切走就停；任务流水存在内存里，重启面板会清空——需要长期留档再说。

## 和本机 DSH 桥接（可选）

主对话里出现「dsh / harness / 小D」这类关键词时，机器人不会自己回答，而是把这句话当成任务转交给本机的 DSH：

1. `设置 → DSH 转交` 里勾「允许转交」；命令留空时会自动找 `%LOCALAPPDATA%\dsh-cli\node_modules\@deepseek-ai\dsh\lib\bin.js`，用 `dsh headless` 跑（一条命令 = 一个任务，跑完退出）。
2. 模型 Key 复用「设置 → 模型 API」里填的那个（以 `DEEPSEEK_API_KEY` 传给 dsh）。
3. 任务结束会回「做完了」+ 完整输出被渲染成一张终端风截图发回 QQ；`GET /api/dsh/jobs` 能看到历史任务。
4. 想自己控制命令，就在 `dsh_command` 里写模板，占位符 `{prompt}` 或 `{prompt_file}`。

## 常见问题

**窗口一闪就没了 / 一直没窗口**
先看 `data/desktop.log`。Electron 的 Chromium 沙箱在部分目录（同步盘、被安全软件加固的文件夹、受限工作区）会直接拒绝启动，脚本检测到这类目录时会自动把运行时复制到 `%LOCALAPPDATA%\qq-persona-bot\runtime` 并从那里启动。想强制重建这份副本，删掉该目录再双击 `start.cmd`。

**端口被占用**
面板默认 7800、OneBot 默认 7801。日志里出现「端口已被占用」就在「设置」里换端口，保存后立即生效。

**模型 401 / 超时**
检查 Key、Base URL（一般以 `/v1` 结尾）和模型名。点「测试连接」会真的发一次请求。

**QQ 起来了，面板还是「未连接」**
面板在 `127.0.0.1:7801/onebot` 上等连接，`protocol\snowcat\SnowCat.9.9.37.Shell\config\onebot11_<QQ号>.json` 里 `network.websocketClients` 的 `url` 必须指向它（结尾是 `/onebot`，不是 `/`）。也可以在雪猫后台的网络配置里核对。

**`start-snowcat.cmd` 提示找不到 `QQ.exe`**
`protocol\snowcat\SnowCat.9.9.37.Shell` 被移走或删了。整份拷回来即可，它是自包含的，不需要重新安装 QQ。

**扫码后登录失败 / 一直转圈**
先用小号、同一个网络环境试；连续失败会触发风控，隔十几分钟再试。QQ 大版本更新后 SnowCat 的注入点可能对不上，等上游适配（本项目用的是 9.9.37 运行时，先别让 QQ 自动升级）。

**机器人回得很「空」/ 像个客服**
「触发规则 → QQ 玩法与网络用语」里确认注入开关是开的；人格设定里把「它是谁、跟对方什么关系、说话习惯」写具体，比堆形容词有效。当前消息越短，越依赖上下文，可以适当调高「携带最近多少条上下文」。

**运行 `start.cmd` 时弹出「打开文件 - 安全警告 / 无法验证发布者」**
批处理脚本（`.cmd`/`.bat`）不支持 Authenticode 数字签名——Windows 只对 exe/dll/msi 这类 PE 文件和 PowerShell 脚本做签名，所以「给 cmd 签名」在技术上不成立。
这个提示来自本机安全软件（联想电脑管家 / 火绒的「程序执行控制」）对未签名脚本的拦截，不是 Windows 的「文件来自 Internet」标记（项目文件里没有任何 `Zone.Identifier`）。
处理办法：弹窗里勾「记住此选择 / 信任此程序」，只需一次；或在 火绒 → 防护中心 → 系统防护 → 程序执行控制 里添加信任，或 联想电脑管家 → 安全 → 信任区 里加上项目文件夹。
想完全绕开脚本：直接双击桌面 **QQ人格机** 快捷方式，它启动的是 `electron.exe`，不经过 `.cmd`。

**为什么用 SnowCat，不用 Lagrange / NapCat / LLBot 了**
Lagrange V1 的 OneBot 仓库已下线、签名服务 `sign.lagrangecore.org` 返回 404；NapCat 官方已收尾（README 只剩一句 Ending）；LLBot 的新用户注册也已关闭（要 Auth Token）。SnowCat 是社区接力方案：NapCat 4.18 内核 + SnowLuma 能力，通过 `winmm.dll` 在 QQ 9.9.37 主进程内注入，仍然输出标准 OneBot 11，所以本项目的接入层一行没改。

**群里不回复**
默认要求 @ 或叫唤词；想让它自由搭话，把「群聊必须 @ 或唤醒词」关掉，再把随机搭话概率调高。
